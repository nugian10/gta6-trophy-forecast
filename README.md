A deterministic, standard-library-only forecaster for GTA VI PlayStation trophy earn rates on Exophase. It decomposes each trophy's earn rate into earners and tracked players, forecasts both to the case target, and emits calibrated 5/25/50/75/95% quantiles on the logit scale.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
